# Unified Cyber Defense Project

## Project Overview
This is a beginner-level cybersecurity project created in a Kali Linux virtual lab.

The project focuses on three areas:
1. Network Traffic Analysis using Wireshark.
2. Linux Log Monitoring using journalctl.
3. Basic Security Hardening Assessment.

## Tools Used
- Kali Linux
- Wireshark
- Linux Terminal
- journalctl
- nftables

## Practical Work Completed

### 1. Network Traffic Analysis
Captured and analyzed ICMP Echo Request and Echo Reply packets using Wireshark.

### 2. Log Monitoring
Reviewed recent Linux system logs and warning-level messages using journalctl.

### 3. Security Hardening Assessment
Checked firewall rules, SSH service status, and available system package updates.

## Lab Environment
- Operating System: Kali Linux
- Virtualization: VirtualBox
- Network Mode: NAT

Screenshots of network traffic analysis, log monitoring, and system update checks are included in this repository.
